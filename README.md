# استمارة البطاقة الوطنية

برنامج ويب (PWA) مجاني لتعبئة استمارة البطاقة الوطنية العراقية من الموبايل، وطباعتها
أو حفظها صورة / PDF مع رمز QR بالصيغة الرسمية. من إعداد هشام احمد.

- كل البيانات تبقى على جهاز المستخدم (localStorage)، ولا تُرسل لأي خادم.
- الاستمارة المطبوعة تُرسم على canvas بحجم A4 مطابق للنموذج الرسمي.
- يعمل بدون إنترنت بعد أول فتح.

## الملفات
- `src/main.js`: الواجهة.
- `src/sheet.js`: رسم الاستمارة المطبوعة.
- `src/qr.js`: بناء بيانات رمز QR.
- `src/schema.js`: الحقول والعناوين.
- `src/texts.js`: نصوص الواجهة ومعلومات التواصل والإعلانات.
- `src/lists.js`: القوائم الرسمية (انظر LICENSES.md).

## التحديث
بعد أي تعديل غيّر قيمة `VERSION` في `sw.js` حتى يصل التحديث لمن ثبّت البرنامج.
